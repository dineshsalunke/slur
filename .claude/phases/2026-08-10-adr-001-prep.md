# 2026-08-10 — ADR-001 PREP: seed → TrackDescriptor + resolveTrack provider

**Phase:** Prep (plan settled with user; ready to implement). **ADR:** `docs/DECISIONS.md` ADR-001.
**Slice type:** pure **structural refactor** — geometry byte-identical; no procgen logic touched.

## Goal
Remove the seed as a first-class concept everywhere *outside the procgen provider module*. The room,
client, sim, and loaders speak `TrackDescriptor` + `Track`. Unblocks ADR-002 (anchors/visual split).

## Decisions settled (this Prep)
1. **Descriptor = discriminated union**, both kinds first-class in the type; **only `procgen` built** now.
   ```ts
   type TrackDescriptor =
     | { kind: 'procgen';  seed: number; tier: number; length: number }
     | { kind: 'authored'; levelId: string }   // reserved arm — provider throws until ADR-002+
   ```
2. **Wire encoding = nested Colyseus sub-schema** `TrackDescriptorState` (typed; matches "schema IS the
   contract"), NOT a JSON string.
3. **`length` and `tier` are RESERVED, UNWIRED.** Fields exist in type + schema; `resolveTrack` ignores
   `tier` and defaults `length` to today's `TRACK_SEGMENTS`. **Rationale (user course-correction):** wiring
   `length` drags in the difficulty-arc / how-long / field-spread questions, which are **procgen rule-system
   design = ADR-003**, not this ADR. Verified the difficulty ramp is absolute/front-loaded (`track.ts:150-151`,
   depends on `START_SAFE`+`D_RAMP_SEGMENTS`, NOT `TRACK_SEGMENTS`), so nothing forces length in here.

## Slice boundary
- **IN:** descriptor type + `resolveTrack` provider; drop the vestigial `Track.seed` (no consumer reads it —
  verified); `pickupLayout(seed)` → `pickupLayout(descriptor)` (procgen branch uses `d.seed` — this is the
  exact seam ADR-002 will re-cut into `track.anchors`); `RunState.seed` → `TrackDescriptorState`; thread the
  descriptor through server + client; **bundle the ADR-004 comment cleanup** (same files).
- **OUT (deferred):** first-class `Track.anchors` + physics/visual split (ADR-002); beat grammar + length/tier
  behaviour + difficulty arc (ADR-003).

## Provider skeleton (shared, new `sim/track-provider.ts`)
```ts
export type TrackDescriptor = /* union above */;
export function resolveTrack(d: TrackDescriptor): Track {
  switch (d.kind) {
    case 'procgen':  return makeProcgenTrack(d);          // = today's makeTrack, seed now internal; finishZ uses d.length ?? TRACK_SEGMENTS
    case 'authored': throw new Error('authored provider not built (ADR-002+)');
  }
}
export function procgenDescriptor(seed: number): TrackDescriptor; // helper: {kind:'procgen', seed, tier:0, length:TRACK_SEGMENTS}
```
- `makeTrack(seed)` becomes procgen-internal (`makeProcgenTrack`); `corridorCenterX(seed)` stays
  procgen-internal. **Seed never leaves this module.**

# Art-direction archive

Archived on 2026-09-20 during the owner-approved artwork cleanup.

The pre-cleanup directory structure is preserved here. All 166 original files were preserved byte-for-byte: 153 files remain in this archive and 13 selected images moved into active subject folders.

- [Current artwork index](../README.md) identifies the selected set and reference limitations.
- [Relocation manifest](relocation-manifest.json) records every original path, destination and SHA-256 checksum.
- Symlinks at the 13 original image locations inside this archive point to the active images, keeping historical image references usable without duplicate image files.
- Old README files, approval labels, plans, briefs and prompts are retained verbatim. Their statuses can be superseded by the current selection.
- Models and model renders are archived separately from the selected vehicle concept sheets, within their original vehicle directories.

This archive covers the former contents of `docs/art-direction` only. Documentation outside that directory and development reference code were left in place. Summarizing and relocating broader art documentation remains a separate step.

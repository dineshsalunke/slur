# Vehicles

Each vehicle folder contains only Markdown documentation, exported 3D models, renders and historical reference images.

- [Comet](comet/README.md): short wide-wing racer; current GLB and matching orthographic renders.
- [Split Crown](split_crown/README.md): selected Freighter design; current GLB, matching renders and earlier Tripo references.
- [Shared explorations](explorations/README.md): comparison boards, selections and generation prompts.

The 3D assets remain art blockouts. Generated concept sheets are visual references, not measured geometry. Claude owns game integration.

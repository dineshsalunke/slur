# Split Crown — material proposal

[Approved material study](../../material-study.png), accepted by the owner on 2026-09-21 and moved into the main Split Crown folder. Built-in image generation from selected concept sheet, with approved scene as mood/colour guidance. Original concept sheet retained.

Proposal: dark coated-metal body, restrained satin highlights, broad panel structure and selective finish wear. Preserve twin crowns, lower central channel, paired L roof lights and four rear engine mouths. Avoid silver outlines becoming the defining shape signal.

Self-review: first output retained strong silver edges and busy scratches; second pass reduced their dominance. Main silhouette and engine count remain recognizable. Some pale bevel highlights and mottled closeup texture persist, and luminous cores still read yellow-white against warmer housings; this is not a verified exact colour match. The small view is an illustrative reduction, not measured gameplay size or proof of runtime readability. Closeup lighting is a study presentation, not validated in-scene lighting.

No exhaust plumes were requested or generated. Deferred exhaust attachment and scene colour drift are not solved by this material board. Main scene remains unchanged.

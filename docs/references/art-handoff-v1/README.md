# SLUR — Art Direction & Scene Production Handoff

**Package:** v1  
**Audience:** Claude / implementation + content creation  
**Purpose:** Begin production of SLUR's environment, track, hazards, and currently frozen pickup/weapon visuals while ship art direction continues separately.

This package is intentionally implementation-oriented. The written rules and the selected images in `GOLDEN_REFERENCES/` together form the frozen visual specification.

## Start here

1. Read `00_STATUS_AND_SCOPE.md`.
2. Read `01_ART_DIRECTION.md` through `05_PICKUPS_WEAPONS.md`.
3. Use `06_IMPLEMENTATION_NOTES_THREEJS.md` and `07_ASSET_CHECKLIST.md` when building content.
4. Use `08_CLAUDE_START_HERE.md` as the working brief for Claude.
5. Consult `SOURCE/SLUR_GDD_v0_current.md` for gameplay/mechanics context, but **do not let stale visual text in the GDD override this handoff**.

## Precedence

If references disagree, use this order:

1. **Explicit rules in this handoff**
2. **Final/golden concept images**
3. **Current gameplay requirements in the GDD**
4. Earlier exploratory concept sheets / generated text inside concept boards

The concept boards are visual references, not dimensional engineering drawings. Any incidental labels, lane counts, measurements, copy, or geometry shown in a board are non-authoritative unless repeated explicitly in this handoff or the GDD.

## North star

> **Cold Space. Warm Energy. Minimal forms. Readable gameplay.**

When implementation choices are close, prefer the simpler solution that preserves silhouette, contrast, gameplay readability, and performance.
